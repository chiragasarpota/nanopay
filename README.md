# nanopay

Nano cryptocurrency toolkit maintained by chiragasarpota.

## Version 0.0.1

This is the initial package setup. It exports only the package version; no wallet, payment, signing, or other cryptocurrency operations are implemented in this release.

```js
const { version } = require('nanopay');
console.log(version); // 0.0.1
```

The next implementation is being developed from [nanocurrency-js](https://github.com/marvinroger/nanocurrency-js), with its upstream copyright notices and GPL-3.0 license preserved.
